# Architecture Rules

Architecture is the highest-priority layer. It outranks the style, the property context and any visual improvement.

## Preserve

- Floorplan geometry, room dimensions and proportions
- Walls, partitions and structural elements
- Columns and beams
- Ceiling structure and ceiling levels
- Doors, including position and swing
- Windows, including count, position and type
- Openings between rooms
- Built-ins and fixed cabinetry
- Singapore fixed features: household shelter door and vent, DB box, service yard, AC ledge, planter, bay window ledge
- Stairs and railings
- Pool and deck geometry
- Any other fixed architectural feature

## Prohibited unless the user asks

- Moving, adding or removing walls or rooms
- Resizing rooms
- Moving, adding or removing doors, windows or openings
- Changing ceiling levels or adding bulkheads
- Moving columns or beams
- Redesigning built-ins
- Mirroring or straightening the layout
- Changing pool shape or position

## Ambiguity

When a feature is unclear, keep what the source visibly supports and record it as uncertain. Do not invent a confident replacement.

If the style conflicts with the architecture, change the styling.
