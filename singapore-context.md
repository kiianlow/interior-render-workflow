# Singapore Property Context

Property context improves realism. It never overrides the supplied architecture. If the source contradicts a typical feature, follow the source.

## Input

- Property type: HDB / Condo / EC / Landed / Other
- Subtype: optional, for example 4-room BTO, 3-bedroom condo, terrace, semi-D
- Level: Ground / Low / Mid / High / Landed
- Approximate size: optional
- Area: optional
- Indoor-outdoor: Balcony / Terrace / PES / Garden / None
- View: as in photo / greenery / neighbouring blocks / open sky / user-stated
- Time of day: late morning / afternoon / golden hour / evening
- Purpose: property marketing / renovation concept / client presentation / other

## Scale

- Size furniture to the room, not to the style.
- Reference sizes: 3-seater sofa about 2.0 to 2.2 m, queen bed about 1.5 x 1.9 m, 4-seater dining table about 1.2 to 1.4 m.
- Walkways of at least 0.8 m where the room allows.
- Ceiling height comes from the source. Never add high ceilings, double volume or bulkheads.

## Fixed features to keep when present

Household shelter steel door and vent, DB box, service yard, AC ledge, planter, bay window ledge, window grilles visible in a photo.

## Common floorplan labels

- HS: household shelter
- BAL: balcony
- PES: private enclosed space, ground floor
- A/C LEDGE, PL (planter): outdoor, not furnished as rooms
- WIC: walk-in closet
- DB: distribution board

## Light

- Near the equator: high, strong sun. Sunrise and sunset stay near 7 am and 7 pm all year.
- Default: late morning daylight softened by sheer curtains.
- Golden hour for hero shots. Evening with interior lights on for mood shots.

## Views

- Keep the view shown in a reference photo.
- Never invent a specific view (sea, landmark, skyline, park) unless the user states it.
- Neutral defaults: ground and low floor, greenery. Mid floor, soft greenery and distant blocks, slightly out of focus. High floor, open sky with distant, low-detail buildings.

## Climate

- No fireplaces, radiators or cold-climate items.
- Ceiling fans suit Singapore homes when the style and ceiling allow.

## By property type

- HDB: practical, compact, true HDB proportions. No hotel-lobby styling.
- Condo and EC: premium and livable.
- Landed: more space, stairs where shown, double volume only when the source shows it.

## Marketing accuracy

Marketing renders must not show features the unit lacks: extra windows, bigger rooms, higher ceilings, better views, balconies or pools that are not in the source. Captions for posted renders should state that the image is virtually staged for illustration.
